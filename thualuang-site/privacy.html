นโยบายความเป็นส่วนตัว

อัปเดตล่าสุด: 6 พฤศจิกายน 2569

"thualuang studio" เป็นเครื่องมือภายในที่เจ้าของเพจถั่วเหลืองใช้เผยแพร่คลิปของตัวเองไปยัง Facebook, Instagram และ YouTube ของเพจถั่วเหลืองเท่านั้น ไม่ได้เปิดให้บุคคลทั่วไปใช้งาน

ข้อมูลที่เข้าถึง

  • สิทธิ์อัปโหลดและเผยแพร่วิดีโอไปยังบัญชีของเจ้าของเพจเอง
  • สถิติของโพสต์ของเพจเอง (ยอดวิว ไลก์ คอมเมนต์ เวลาดูเฉลี่ย) เพื่อวิเคราะห์ผลงาน

การใช้และการเก็บข้อมูล

ข้อมูลและโทเค็นการเข้าถึงถูกเก็บไว้บนคอมพิวเตอร์ของเจ้าของเพจเท่านั้น ไม่ขาย ไม่แชร์ และไม่ส่งต่อให้บุคคลที่สาม ไม่มีการเก็บข้อมูลส่วนบุคคลของผู้ชม

การใช้ข้อมูลที่ได้รับจาก Google API เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use และการใช้ YouTube API เป็นไปตาม ข้อกำหนดการให้บริการของ YouTube และ นโยบายความเป็นส่วนตัวของ Google

การลบข้อมูล

ยกเลิกสิทธิ์ได้ทุกเมื่อที่ myaccount.google.com/permissions และในการตั้งค่า Facebook > แอปและเว็บไซต์ หรือติดต่อขอลบข้อมูลทางอีเมลด้านล่าง
